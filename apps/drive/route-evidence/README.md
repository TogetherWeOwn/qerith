# Drive folder route evidence (NVDA + Firefox)

After the reviewed harness reaches `main`, an Actions write collaborator can invoke it while #139 is open, including while it is a draft:
```sh
head=$(gh pr view 139 --repo TogetherWeOwn/qerith --json headRefOid --jq .headRefOid)
gh workflow run drive-route-evidence.yml --repo TogetherWeOwn/qerith --ref main -f source_sha="$head"
```
Link the run and `drive-folder-route-<source SHA>-<attempt>` from #139. Compare `provenance.json` with the current #139 head and the run's `main` SHA; re-dispatch on drift. Pull requests changing the harness exercise an NVDA smoke route (including two no-link unavailable documents) and a Firefox focus-transition control, but have no product source SHA or product verdict.

The job projects the real route, app document and library into an ephemeral loopback preview, injecting synthetic authorization and `ReadAccess` at the reviewed loader call. If the loader changes, the projection refuses it until the seam is re-reviewed. No credential persistence, Worker, shipped hooks, real accounts or deployment. The [hosted example](https://github.com/guidepup/guidepup/actions/runs/42476096312/job/128717690171) used the same Windows image family, Playwright Firefox and [Guidepup NVDA](https://github.com/guidepup/nvda/releases/tag/0.2.1-2026.3). Both executable archives are digest-checked. The job checks manifest/lock agreement, locked registry age and integrity, and disables non-registry sources and install scripts. On the disposable hosted VM, an active inbound rule blocks non-loopback access to the NVDA relay before it starts, for both address families. The rule stays in force until the VM is destroyed. Refresh the pinned relay certificate before May 29, 2027.

- `provenance.json`, `tools.json`, `browser.json`: commits, run/attempt, Windows image, binary versions and archive hashes. `result.json`: `runner-self-check` or `exact-head-route` with `status: captured`. A failed job or incomplete artifact is not a pass; report the specific failure and link any partial artifact.
- `speech.jsonl`: keyboard steps (including NVDA activation), destinations and unchanged speech. Denied/missing direct arrivals must each speak the generic title, document role and named level-1 heading. Compare the complete arrival and separately captured title speech after whitespace normalization. Document status, headers except Date and body must also match (including signed out) in `unavailable-*.json`. An unequal response is not saved; the log identifies the differing field. Missing speech or full navigation fails; no tree substitute. Continuation exercises real cursor-row removal, not production page sizing or concurrent metadata changes.
- `axe-*.json`, `keyboard-*.json`, `motion-*.json`, screenshots: 390/1280 checks (including signed out), 320 px reflow, greyscale, forced colours and Tab stops under reduced motion. Review focus, labels, contrast/token pairs, layout and copy against [Drive accessibility](../../../docs/design/accessibility.md#12-design-qa-checklist). This is not integrated staging or complete manual design QA.
